# Séances Hand

Site gratuit pour les entraîneurs de handball : on choisit un thème, une catégorie, une durée et le nombre de joueurs, et le site propose une séance complète (échauffement, exercices progressifs, situation de jeu, retour au calme) avec une planche tactique animée pour chaque exercice.

## Thèmes disponibles

- Attaquer une défense 1-5
- Défendre en 1-5
- Démarquage et appel de balle
- Jeu dans l'intervalle (débutants)
- Contre-attaque et montée de balle
- Jouer avec le pivot
- Gardien de but
- Gagner le duel défensif
- Jeux d'initiation (école de hand)

## Utilisation

Le site tient dans un seul fichier, `index.html`. Il suffit de l'ouvrir dans un navigateur, ou de le publier avec GitHub Pages.

## Contenu

Les fiches d'exercices sont rédigées et dessinées pour ce site, à partir des principes de la formation en handball. Elles doivent être relues par un entraîneur avant toute publication.
